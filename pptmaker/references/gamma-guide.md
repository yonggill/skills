# Gamma Formatting & Best Practices Reference

Phase 4에서 Gamma 프롬프트 파일을 생성할 때 참조하는 가이드.

---

## 1. Gamma 마크다운 파싱 규칙

### 1.1 카드 구분
- **`---` (horizontal rule)** 로 카드/슬라이드 구분
- 각 `---` 사이의 콘텐츠가 하나의 카드로 변환됨
- `---` 앞뒤에 빈 줄 권장

### 1.2 지원 마크다운 문법
| 문법 | 지원 여부 | 비고 |
|------|---------|------|
| `#`, `##`, `###` | O | Heading 1-3 |
| `**bold**` | O | 강조 |
| `*italic*` | O | |
| `- bullet` | O | 비순서 목록 |
| `1. item` | O | 순서 목록 |
| `> blockquote` | O | 인용/강조 블록 |
| 코드 블록 | O | `/` 메뉴 통해 삽입 |
| 테이블 | X | Gamma가 자체 생성하므로 마크다운 테이블 비권장 |
| 인라인 HTML | X | 무시됨 |

### 1.3 Heading 위계와 카드 구조
- `#` (H1): 프레젠테이션 전체 제목 — 파일에서 1회만 사용
- `##` (H2): 각 카드의 제목 — 카드당 1개
- `###` (H3): 카드 내 하위 섹션 — 선택적, 카드 내에서만

## 2. 콘텐츠 최적화 규칙

### 2.1 밀도 제한
- 카드당 불릿 **최대 6개**
- 불릿당 **최대 30단어**
- 카드당 핵심 메시지 **1개**
- 불필요한 부연 설명 제거 — Gamma가 디자인으로 보완

### 2.2 구조 원칙
- **짧고 구조화된 콘텐츠** > 긴 단락
- 불릿 리스트 > 서술형 문장
- 핵심 키워드 **볼드** 처리
- 한 불릿에 2줄 이상 금지

### 2.3 비교/대조 콘텐츠
테이블 대신 라벨+불릿 구조 사용:

```markdown
**Before**
- 문제점 1
- 문제점 2

**After**
- 개선점 1
- 개선점 2
```

Gamma가 이를 비교 레이아웃으로 자동 변환.

## 3. 이미지 & 비주얼 가이드

### 3.1 이미지 힌트 형식
Gamma AI 이미지 생성을 위해 blockquote로 이미지 설명 삽입:

```markdown
> Image: [구체적 묘사]
```

### 3.2 SPLICE 이미지 프롬프트 공식
좋은 AI 이미지를 위한 6요소:

| 요소 | 설명 | 예시 |
|------|------|------|
| **S**etting | 장소/환경 | 모던한 오피스, 컨퍼런스 룸 |
| **P**eople | 인물/역할 | 다양한 인종의 팀원 3명 |
| **L**ighting | 조명 | 따뜻한 자연광, 소프트 라이팅 |
| **I**mmediacy | 분위기/감정 | 협업적, 에너지 넘치는 |
| **C**omposition | 구도/프레이밍 | 미디엄 샷, 약간 위에서 내려다보는 앵글 |
| **E**xecution | 스타일 | 사실적 사진, 미니멀 일러스트 |

### 3.3 차트/그래프 힌트
```markdown
> Chart: [차트 유형] — [데이터]
> 예: 연간 매출 성장 (막대 차트) — 2023: 50억, 2024: 80억, 2025: 120억
```

### 3.4 이미지 품질 팁
- 추상적 설명 (`좋은 이미지`) 보다 구체적 묘사 (`밝은 자연광이 드는 미니멀 사무실에서 노트북으로 작업하는 개발자`)
- 상충되는 요소 금지 (`어두운 분위기`와 `밝은 오피스` 동시 사용 금지)
- AI 초상화가 부자연스러울 수 있음 — 중요한 인물 사진은 스톡 이미지 사용 권장

## 4. Speaker Notes

### 4.1 Gamma 지원 현황
- Gamma는 **붙여넣는 마크다운에서 speaker notes를 자동 파싱하지 않음**
- 생성 후 각 카드의 우상단 아이콘에서 수동 추가
- Gamma AI가 슬라이드 콘텐츠 기반으로 speaker notes 자동 생성 가능

### 4.2 별도 파일 전략
`{topic}-speaker-notes.md`에 슬라이드 번호별로 정리:

```markdown
## Slide 1: 타이틀
[speaker notes 없음]

## Slide 2: 문제 정의
"오늘 논의할 핵심 문제는..."로 시작.
시장 조사 데이터 출처: McKinsey 2025 보고서.
이 슬라이드에 1분 30초 할당.

## Slide 3: 솔루션
이전 슬라이드의 문제를 자연스럽게 연결: "이 문제를 해결하기 위해..."
데모가 가능하면 여기서 라이브 데모 전환.
```

## 5. Gamma 제약 및 주의사항

### 5.1 생성 제한
- 한 번에 **최대 30장** 생성
- 생성 후 무제한 카드 추가 가능
- API 입력 제한: ~5,000자 (텍스트 모드)

### 5.2 내보내기
- **PDF 권장** — 레이아웃이 정확히 유지됨
- **PPTX 주의** — 폰트 대체, 텍스트 박스 위치 이동, 슬라이드 크기 불일치 가능
- PPTX 내보내기 후에는 반드시 검토 및 수정 필요

### 5.3 디자인 특성
- Gamma는 자체 테마 시스템으로 디자인 처리 — 마크다운에 스타일 지정 불필요
- 워크스페이스 테마를 미리 설정하면 브랜드 일관성 유지 가능
- Theme Editor에서 AI 이미지 스타일 키워드 설정 가능
- 반복 사용 시 비슷한 디자인이 나올 수 있음 — 테마 변경으로 다양성 확보

### 5.4 한국어 특이사항
- 한국어 텍스트는 잘 지원됨
- 한 불릿의 텍스트가 길면 카드 밀도가 높아져 가독성 저하
- **50자 이상 문장은 분할** 권장
- 영문/한글 혼용 시 띄어쓰기 통일: `AI 기반`, `SaaS 플랫폼`

## 6. 생성 후 최적화 팁

1. **Enhance 버튼** — 각 카드의 Enhance로 디자인 자동 개선
2. **이미지 재생성** — 마음에 들지 않는 이미지는 개별 카드에서 재생성
3. **카드 분할/병합** — 밀도가 높은 카드는 분할, 빈약한 카드는 병합
4. **테마 실험** — 같은 콘텐츠로 다른 테마 적용 시 전혀 다른 느낌
5. **2단계 워크플로** — Outline → 조정 → Generate → 수동 보정
